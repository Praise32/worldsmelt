# Regole negative — cosa NON fare (v2 draft, 31/07/2026)

Dalla Fase A/B della reference distillation + regole del proprietario.

1. **Mai volti** sui personaggi: niente occhi, musi, trattini — vuoto nero
   sotto cappucci/elmi. (Le reference con volti si usano solo per il resto.)
2. **Mai armi in mano** nei personaggi base: l'arma è un oggetto (slot DEC-049).
3. **Mai dithering.** Mai noise fill: la texture è motivo geometrico o accento
   sparso ≤10–15%.
4. **Mai linee rette lunghe** sui bordi organici: gradini irregolari.
5. **Mai campiture piatte grandi** senza piano di luce o accento.
6. **Mai colori fuori palette Fucina** (31, non-neon). Il ciano acceso e le
   palette Material Design delle reference si rimappano sempre.
7. **Mai pixel isolati accidentali** (solo scintille deliberate).
8. **Mai outline nero perimetrale, da nessuna parte** (deciso 31/07: opzione B).
   Bordo implicito = tono più scuro del materiale. Obbligo di floor test
   chiaro/scuro per ogni asset.
9. **Mai frame duplicati come cel separati**: usare cel linkati.
10. **Mai guide visibili negli export** (guida su livello nascosto).
11. **Mai più di ~8 colori per entità** (budget 3–8).
12. **Mai il modello "piccola illustrazione"**: a ogni scala vince la
    silhouette; il dettaglio interno si sacrifica per primo (lezione 16↔32).
13. **Mai copiare design dalle reference**: solo principi astratti; le
    reference commerciali rippate non entrano nel repo né nei dataset.
14. **Mai upscalare micro-pattern tra scale**: si riprogettano.
