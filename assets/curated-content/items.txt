# Curated item pool (W5b, DEC-153, DEC-087 minimum-curated table: 20 required, DEC-144
# floor: at least one item of every rarity). Format: src/content/curated_catalog.h
# (ReadOneItem) -- item<N>.<key>=<value>, one record per item, 1-based, sentinel is a
# missing "item<N>.name=". Same vocabulary as a real melting-gen run/fallback
# (ItemKindFromText/RarityFromText/ItemTraitsFromText, src/content/run_content.h,
# src/gameplay/item_traits.h): slot in {hat,eyes,hand,back,body,aura}; kind in
# {passive,active,graft,statup} (a record that says "active" but declares neither
# charges nor cooldown reads back as passive -- see the compatibility table in
# items-pools-and-rarity.md, so every genuinely active entry below declares one of the
# two); rarity in {common,uncommon,rare,legendary}; traits: 1-2 of
# {bounce,homing,explode,split,pierce,rapid,giant,slow,vamp}; script is the mini-VM CSV
# "trigger:op,a,b,trait" (on_fire only pairs with burst; on_hit pairs with
# projectile/area/heal), bounds-checked at generation time against the same OP_BOUNDS
# table melting-gen itself uses (tools/melting-gen/gen_validate.c). A statup entry never
# carries a script (taxonomy invariant, enforced again defensively by the loader).
#
# Origin: real bin/melting-gen runs, model models/gemma-3-4b-it-q4_k_m.gguf, offline,
# seeds 100001/200002/300003 (registered here, not hand-invented -- the model always
# invents the actual content, per the house rule in shot_type.h/enemy_type.h). 25 of the
# ~45 items generated across the three seeds were kept (24-30 target range); the rest were
# rejected as weak/redundant, see below. No lua= wiring: every generated .lua for this
# batch was inspected, and several were functionally weak or outright broken (e.g. a script
# calling player_damage(x) as if it were a setter -- it is read-only -- with the model's
# own comment admitting the bug; another that computes values and discards them, spawning
# only a cosmetic particle, violating the generator's own "every object must create a
# small, playable synergy" rule). The mini-VM script= field is the safety net's fallback;
# using it for all 25 entries keeps every curated behavior deterministic and already
# bounds-checked, at the cost of the extra per-item flourish real Lua would add -- flagged
# as a follow-up, not a silent omission.
#
# Content-designer review pass (tone DEC-105 n/a to World content per narrative-tone.md
# "l'ironia sta nella voce del crogiolo, non nel mondo generato"; DEC-119 dark-~16+ limits
# checked, none triggered; 09-originality-guardrails.md vocabulary checked, none present):
# 7 entries renamed for weak name-effect coherence (kept mechanically identical, name
# only) -- "Lantern Bulb"->"Ember Husk", "Ice Pick"->"Shattering Icepick", "Steam Vent"->
# "Leeching Vent" (seed 100001); "Root"->"Root Tendril", "Glass"->"Glass Splinter", "Clay"->
# "Cracked Clay Ward", "Spindle"->"Spindle Coil" (seed 200002).
#
# Entries REJECTED, with reason:
# - seed 200002: "Charm"/"Fragment"/"Bell" each generated TWICE across that run's 5
#   floors (the model repeated itself, violating its own prompt's "no name repeats" rule)
#   -- the second occurrence of each was dropped rather than renamed/kept.
# - seed 300003, floors 4-5: the model degenerated into literal self-repetition -- every
#   name from floors 1-2 reappears on floors 4-5 with a bare " 2" suffix ("Glass Grub 2",
#   "The Lensmith 2", "Prism Shard 2", ...), including the FLOOR THEME ITSELF
#   ("Aqueduct of Wind-Up 2") -- a generation failure, not a stylistic choice. Both floors
#   discarded wholesale (items, enemies and bosses).
# - seed 300003, floor 3: "Prisms"/"Dice Twirls"/"Bubble Veil" are near-duplicates of
#   floor 1's "Prism Shard"/"Dice Coil"/"Bubble Stone" (same trait/slot/script family,
#   same name root) -- redundant rather than varied, dropped in favor of the floor-1
#   originals already kept.
#
# tags= (comma list) is read only by scripts/curated-map.py for image auto-matching; the
# game engine ignores it entirely.
