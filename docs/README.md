# Documentazione interna

Questa cartella raccoglie gli appunti e le decisioni da consultare durante lo sviluppo.

- `APPUNTI.md`: idea iniziale e direzioni sperimentali.
- `DESIGN_NOTES.md`: note sul design del prototipo.
- `ISSUE_NOTES.md`: problemi già incontrati e verifiche future.
- `OPENAI_SETUP.md`: configurazione della pipeline OpenAI.
- `ARCHITECTURE.md`: struttura modulare corrente e regole per estenderla.
- `LOCAL_REFERENCES.md`: ruolo dei repository locali Raylib, Raygui, IsaacDocs e GGUF.

`README.md` resta intenzionalmente alla radice perché GitHub lo usa come pagina iniziale della repository.
