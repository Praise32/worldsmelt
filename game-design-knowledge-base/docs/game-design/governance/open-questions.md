# Open Questions

Le risposte vanno trasferite nei documenti pertinenti e registrate in `decision-log.md`.

## Priorità alta

1. Qual è il tema narrativo originale del gioco?
2. Come si chiama il progetto e quale vocabolario sostituisce i riferimenti provvisori presi da altri giochi?
3. Come si controlla il personaggio: doppio stick, quattro direzioni, mira libera o altro?
4. Qual è la durata obiettivo di una run completa di cinque piani?
5. Il primo piano ha sempre lo stesso layout, usa un set di layout curati o è procedurale ma non generato dall'IA?
6. I piani 2-5 condividono un tema di run o hanno temi distinti?
7. Quali contenuti può creare completamente l'IA e quali devono essere soltanto combinazioni di moduli validati?
8. Qual è il tempo massimo accettabile prima dell'avvio della run?
9. Che cosa accade se il piano successivo non è pronto quando il giocatore raggiunge l'uscita?
10. Quali sono le statistiche base del giocatore e quali possono essere modificate?
11. Quali tipi di salute esistono e in quale ordine vengono consumati?
12. Quanti slot esistono per attivi, passivi e trinket?
13. Qual è il limite di complessità visiva delle sinergie?
14. I contenuti generati vengono ricordati e possono tornare in run future?
15. Come viene definita la vittoria di una run?

## Multiplayer

16. Gara simultanea online o sfida asincrona?
17. I giocatori affrontano la stessa run esatta?
18. Qual è la metrica principale: tempo, punteggio o combinazione?
19. Che cosa accade in caso di disconnessione?
20. Quali assistenze rendono una run non classificata?

## Economia e stanze

21. Quali risorse sono definitive?
22. Quali archetipi di stanza speciale fanno parte del gioco base?
23. Come vengono individuate le stanze segrete?
24. Esistono prezzi dinamici o costi in salute?
25. Quanti oggetti medi vengono offerti per piano?

## Modalità

26. La modalità caos elimina quali vincoli?
27. La modalità standard permette contenuti completamente nuovi o solo composizioni validate?
28. Esiste una modalità offline senza generazione nuova?

## Produzione

29. Quali contenuti curati devono esistere per garantire una run completa di fallback?
30. Qual è il minimo gioco base da completare prima di espandere la generazione IA?
