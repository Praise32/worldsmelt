# Run Structure

## Struttura corrente

Una run standard contiene cinque piani.

### Piano 1 — Fondazione affidabile

- Sempre disponibile all'avvio della run.
- Costruito con contenuti preesistenti e validati.
- Introduce il tono e permette al giocatore di iniziare senza attese lunghe.
- Durante questo piano viene preparato il contenuto dei piani successivi.

### Piani 2-4 — Espansione generata

- Usano contenuti generati o composti per la run.
- Aumentano gradualmente varietà, difficoltà e interazioni.
- Mantengono una coerenza tematica per piano o per run.

### Piano 5 — Culmine

- Deve chiudere l'arco della run.
- Contiene una sfida finale o un boss con relazione leggibile alla build e al tema della run.
- La sua generazione deve essere completata e validata con sufficiente anticipo.

## Budget di novità proposto

Non tutto deve essere nuovo contemporaneamente. Ogni piano definisce un budget massimo di:

- nuove famiglie di nemici;
- nuove regole ambientali;
- nuove categorie di ricompensa;
- nuovi effetti visivi dominanti.

## Fallback

Se un piano generato non è pronto o non supera la validazione:

1. usare un piano di fallback curato;
2. mantenere la build corrente;
3. registrare l'evento senza interrompere la run;
4. non mostrare dettagli tecnici al giocatore durante il combattimento.

## Preparazione di run future

La pre-generazione di una run futura è opzionale e non deve ridurre la stabilità o la leggibilità della run attuale.
