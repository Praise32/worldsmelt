# Passive Items

## Contratto

Ogni passivo deve dichiarare:

- proprietà modificate;
- tag di sinergia;
- trasformazioni visive;
- stacking;
- limiti;
- incompatibilità;
- valore nel budget di potenza.

## Regola

Un passivo generato deve avere almeno un effetto distinguibile e descrivibile in una frase semplice.
