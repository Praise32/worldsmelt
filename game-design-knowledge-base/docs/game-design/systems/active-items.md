# Active Items

## Contratto

Ogni oggetto attivo deve definire:

- input di attivazione;
- cariche o cooldown;
- condizioni d'uso;
- effetto;
- feedback;
- comportamento se non può essere usato;
- interazioni con altri oggetti attivi;
- persistenza tra stanze e piani.

## Principio

L'oggetto attivo deve creare una decisione sul momento d'uso, non essere un bonus automatico privo di scelta.
