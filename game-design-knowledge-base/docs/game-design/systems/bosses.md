# Bosses

## Ruolo

Il boss verifica abilità e decisioni sviluppate nel piano, senza dipendere da una singola build obbligatoria.

## Struttura minima

- identità e tema;
- arena;
- fasi;
- pattern principali;
- transizioni leggibili;
- contromisure;
- ricompensa;
- condizioni anti-stallo;
- fallback.

## Boss generati

Un boss può essere composto da moduli, ma deve apparire come un'entità coerente e non come una lista casuale di attacchi.

## Limite

Il boss finale non deve introdurre contemporaneamente troppe regole mai viste nella run.
