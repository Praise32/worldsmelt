# Synergies

## Definizione

Una sinergia esiste quando due o più componenti producono un risultato più specifico della semplice somma delle statistiche.

## Livelli

1. **Statistica:** modifica valori.
2. **Comportamentale:** cambia traiettoria, cadenza, bersaglio o interazione.
3. **Visiva:** fonde aspetti di proiettili, personaggio ed effetti.
4. **Sistemica:** interagisce con risorse, stanze o nemici.

## Regola di composizione visiva

Ogni effetto fornisce strati o tratti compatibili. Esempio astratto:

- tratto A: proiettile appuntito;
- tratto B: proiettile incendiario;
- risultato: forma appuntita con materiale ed effetti di combustione;
- personaggio: indicatori visivi coerenti con entrambi i tratti.

## Priorità

Quando più effetti competono sulla stessa proprietà:

1. trasformazioni esplicite;
2. regole di fusione definite;
3. priorità di categoria;
4. fallback visivo e meccanico sicuro.

## Limiti

- Massimo numero di strati visivi leggibili da definire.
- Effetti incompatibili devono dichiarare esclusione o trasformazione.
- Nessuna sinergia può rendere invisibili minacce fondamentali.

## Informazione al giocatore

La schermata build deve spiegare quali componenti hanno prodotto la sinergia, senza necessariamente rivelare formule interne.
