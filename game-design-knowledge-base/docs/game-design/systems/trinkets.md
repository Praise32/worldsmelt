# Trinkets

## Ruolo

I trinket offrono modifiche situazionali, economiche o di supporto. Devono essere facili da sostituire e creare scelte di adattamento.

## Da definire

- numero di slot;
- possibilità di drop volontario;
- stacking;
- rarità;
- relazione con oggetti passivi;
- persistenza tra piani.
