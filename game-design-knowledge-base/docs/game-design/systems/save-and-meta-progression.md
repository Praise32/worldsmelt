# Save and Meta Progression

## Cosa può essere salvato

- impostazioni;
- sblocchi;
- catalogo delle scoperte;
- statistiche;
- risultati e classifiche;
- run sospesa, se prevista;
- manifest condivisi.

## Principio

La perdita di una run non deve corrompere il profilo. La progressione persistente non deve rendere irrilevante la competenza del giocatore.

## Domande aperte

- La run può essere sospesa e ripresa?
- I contenuti generati entrano in un catalogo permanente?
- Gli oggetti scoperti possono riapparire in run future?
