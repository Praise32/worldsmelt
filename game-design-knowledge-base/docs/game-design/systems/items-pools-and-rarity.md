# Items, Pools and Rarity

## Categorie iniziali

- Oggetti passivi.
- Oggetti attivi.
- Trinket.
- Consumabili.
- Ricompense speciali.

## Pool

Un oggetto appartiene a uno o più pool tematici o funzionali. Esempi astratti:

- ricompense standard;
- tesoro;
- rischio elevato;
- protezione;
- mobilità;
- trasformazione dei proiettili;
- economia;
- boss;
- segreto.

## Rarità e peso

La rarità non deve essere l'unico indicatore di potenza. Ogni oggetto possiede almeno:

- rarità;
- peso nel pool;
- budget di potenza;
- tag;
- prerequisiti;
- esclusioni;
- valore della sinergia;
- costo o rischio, quando presente.

## Controllo della run

Il sistema deve evitare:

- troppe ricompense della stessa categoria;
- build senza possibilità di scalare;
- offerte inutilizzabili senza alternativa;
- ripetizioni eccessive;
- combinazioni note come non valide.

## Pity e correzione

È ammesso un correttore invisibile che aumenti la probabilità di categorie mancanti, senza garantire sempre la soluzione perfetta.
