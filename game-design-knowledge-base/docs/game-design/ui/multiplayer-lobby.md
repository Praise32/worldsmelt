# Multiplayer Lobby

## Elementi

- partecipanti;
- modalità;
- regole della run;
- stato pronto;
- classificata/non classificata;
- codice o identità della sfida;
- avvio.

## Avvio

L'host o il sistema avvia soltanto quando tutti i partecipanti hanno ricevuto e validato la stessa definizione competitiva.

## Uscita

Uscire prima dell'avvio non assegna una sconfitta. Dopo l'avvio valgono le regole della modalità.
