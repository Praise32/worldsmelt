# Main Menu

## Elementi proposti

| Elemento | Disponibilità | Risultato |
|---|---|---|
| Nuova run | Sempre | Apre configurazione run |
| Continua | Se esiste una run sospesa valida | Riprende la run |
| Multiplayer | Se la modalità è disponibile | Apre lobby |
| Classifiche | Se disponibili | Apre classifiche |
| Catalogo | Se previsto | Mostra scoperte |
| Opzioni | Sempre | Apre opzioni |
| Esci | Piattaforme applicabili | Mostra conferma |

## Focus

Il focus iniziale va alla principale azione disponibile. Se esiste una run sospesa, la priorità tra Continua e Nuova run è una decisione aperta.

## Errori

Se un servizio opzionale non è disponibile, il single player deve rimanere accessibile.
