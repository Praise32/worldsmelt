# Run Setup

## Opzioni iniziali

- modalità standard;
- modalità caos;
- run condivisa tramite codice o manifest;
- eventuali modificatori sbloccati;
- personaggio, se ne esistono più di uno.

## Azione Avvia

1. valida le scelte;
2. crea l'identità della run;
3. verifica che il primo piano sia disponibile;
4. avvia o mostra lo stato di generazione;
5. impedisce input duplicati.

## Regola

Il giocatore deve sapere quali opzioni incidono su classifiche e confrontabilità.
