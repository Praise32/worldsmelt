# Inventory and Synergy Screen

## Contenuto

- oggetti acquisiti;
- trinket;
- oggetto attivo;
- statistiche principali;
- sinergie attive;
- effetti temporanei;
- origine delle trasformazioni visive.

## Regola di comprensione

Selezionando una sinergia, il giocatore vede:

- componenti coinvolti;
- risultato comportamentale;
- modifiche visive;
- eventuali esclusioni o limiti.

## Non mostrare necessariamente

- formule interne complete;
- prompt dell'IA;
- punteggi di validazione tecnici.
