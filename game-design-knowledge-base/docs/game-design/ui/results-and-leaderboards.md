# Results and Leaderboards

## Risultati della run

- esito;
- tempo;
- piano raggiunto;
- boss sconfitti;
- build finale;
- sinergie notevoli;
- punteggio;
- identificatore condivisibile della run;
- fallback rilevanti, se incidono sulla validità competitiva.

## Classifica

Ogni voce deve essere legata a modalità, versione delle regole e run o stagione.

## Azioni

- nuova run;
- riprova la stessa run, se consentito;
- condividi identificatore;
- visualizza dettagli;
- torna al menu.
