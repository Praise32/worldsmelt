# Pause Menu

## Azioni

- Riprendi.
- Visualizza build e sinergie.
- Opzioni.
- Riavvia run, se consentito.
- Abbandona run con conferma.

## Decisione critica

Definire se la simulazione si ferma in single player e come si comporta in multiplayer.

## Regole

- Nessuna azione distruttiva immediata.
- Il focus iniziale è Riprendi.
- Tornando dalle opzioni, il focus ritorna su Opzioni.
- L'abbandono registra correttamente risultato e stato competitivo.
